# yl

Codex CLI 的桌面管理面板 —— Rust + Tauri 应用。

把 Codex CLI 日常要改的几件事集中到一个界面里：中转站地址与 API Key、代理开关、指令文件（bridge.md）、响应替换规则、技能模块、模型选择，以及一个内置对话页（不用开终端就能和 Codex 对话）。代理启动时自动备份并改写 `~/.codex/config.toml`，停止时还原。

## 它解决什么问题

手动管理 Codex CLI 的环境比较麻烦，通常要反复做这些事：

- 改 `~/.codex/config.toml` 切换中转站地址，改完还得记得改回去
- 手动往 `~/.codex/skills` 里复制/删除技能目录
- 想换模型得去查接口、手填模型名
- 换个目录用 Codex，就要换个终端重新进

yl 把上面这些做成界面操作：代理开关负责配置的备份与还原，技能和模型都是点一下的事，对话页可以直接指定工作目录，不用开终端。

## 特性

| 模块 | 说明 |
|---|---|
| **本地代理** | 在 `127.0.0.1:8080` 接管 Codex CLI 的上游请求并转发到中转站；开启代理走管道，关闭后自动恢复直连 |
| **指令注入** | 把请求中的 system 提示词替换为 `bridge.md` 的内容，该文件可直接编辑 |
| **响应替换** | 39 条正则规则（中/英/俄/日）匹配到拒绝类回复时自动替换；规则存于 `tamper-rules.txt`，改完重启代理生效 |
| **记忆** | 成功交互的记录写入 `memory.json` |
| **技能管理** | 28 个 skill 模块一键部署到 `~/.codex/skills`，支持还原、单独启用/禁用 |
| **模型管理** | 从上游拉取可用模型列表，点选即保存，下次启动自动沿用 |
| **对话页** | 面板内直接与 Codex 对话：后台调用 `codex exec`，按会话 ID 续接多轮，可指定工作目录，无需另开终端 |
| **仪表盘** | 实时显示每次交互的类别、字节数、耗时与是否被替换 |
| **配置管理** | 填写中转站地址与 API Key；启动代理时自动备份 `config.toml`，停止时还原 |

## 请求流程

以「对话页」发一条消息为例：

```
对话页 ──▶ codex exec ──▶ 本地代理 :8080 ──▶ 替换 system 提示词为 bridge.md
                                          ──▶ 转发到中转站
                                          ──▶ 收到回复后按 39 条规则检查
                                          ──▶ 命中拒绝类回复则替换
                                          ──▶ 记录到 memory.json 并推送到仪表盘
                                          ──▶ 返回给对话页显示
```

代理未启动时，Codex 直接连中转站，不经过上面任何一步。

## 使用方法

**环境要求**：Windows 10 / 11（界面使用系统自带 WebView2）。

需自行安装 Node.js 18+ 与 Codex CLI：

```bash
npm install -g @openai/codex
```

安装后先运行一次 Codex CLI，生成 `~/.codex` 目录。

**使用步骤**：

1. 下载本仓库 `yl.exe`，与 `codex-skills/`、`bridge.md` 放在同一目录（建议用户目录，如桌面 / 文档）
2. 双击 `yl.exe` →「配置管理」填入上游地址与 API Key
3. 「获取模型列表」→ 点选模型
4. 「启动代理」：自动备份并改写 `~/.codex/config.toml`，部署 bridge.md 与技能模块
5. 在 Codex CLI 中对话，或直接用内置「对话」页
6. 「停止代理」自动还原配置；异常退出下次启动自动恢复

## 文件说明

```
├── yl.exe                 # 主程序（便携版，免安装）
├── codex-skills/          # 28 个任务模块（需与 exe 同目录）
├── bridge.md              # 会话指令配置（可自行编辑）
├── tamper-rules.txt       # 输出改写规则（可自行编辑）
└── 使用说明.txt            # 完整使用文档
```

> `memory.json`、`logs/` 首次运行后自动生成。

## 文件校验


```powershell
Get-FileHash .\yl.exe -Algorithm SHA256
```
