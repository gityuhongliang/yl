yl v0.01 — 使用说明
========================================

【这是什么】
Codex CLI 的图形化管理工具：本地代理 + 会话指令 + 改写规则 + 记忆内核
+ 技能管理 + 模型管理 + 内置对话页。便携版，解压即用。


【运行环境】
1. Windows 10 / 11（依赖系统 WebView2，一般自带）
2. 必须先安装 Codex CLI（需要 Node.js 18+，https://nodejs.org）：

       npm install -g @openai/codex

   安装后先在命令行运行一次 codex，让它生成 ~/.codex 目录。

【怎么用】
1. 双击 yl.exe
2. 「配置管理」页填写：
     中转站地址：你的上游 API 地址（形如 https://xxx/v1）
     API Key   ：你的密钥
3. 「获取模型列表」→ 点击选择一个模型
4. 「启动代理」——自动备份并改写 ~/.codex/config.toml
5. 用 Codex CLI，或直接在应用内「对话」页对话
6. 用完点「停止代理」还原配置（异常退出后下次启动自动恢复）

【目录说明】
  codex-skills/      28 个技能模块（必须与 exe 同目录）
  bridge.md          会话指令集，可自行编辑
  tamper-rules.txt   改写规则（首次运行自动生成，可编辑）
  memory.json        记忆数据（自动生成）
  logs/              运行日志（自动生成）

【常见问题】
  · 提示「未找到 codex.js」        → 未安装 Codex CLI，见「运行环境」第 2 条
  · 提示「未找到有效的中转站地址」  → 先在配置页填地址，再启动代理
  · 请把本文件夹放在用户目录（桌面 / 文档），不要放 C:\Program Files
    （程序需要在同级目录写日志与配置）
